Évolution

Tout est compté en nombre de tickets (les bugs n'ont pas de points). L'avancement pondéré est un indicateur secondaire : Σ(poids du statut) / nb tickets, poids configurables. « PRJ301 » = étiquette SourceProject_PRJ301 dans Labels (tests fournis par le projet de test) ; les autres sont nos bugs internes. « Target date dépassée » = tickets non terminés dont la Target date est antérieure à la date de référence. Cliquez sur n'importe quel chiffre, barre, cellule ou alerte pour retrouver les tickets (avec leur résolution) et les rouvrir dans Jira. Données collées et préférences d'affichage conservées dans ce navigateur ; configuration et journal partagés via Supabase quand vous êtes connecté.
