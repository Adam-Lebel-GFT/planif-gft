Stabilisation · Cadence en train (chevauchement)

Plan de livraisons de stabilisation

Une ligne par version, avec ses phases et ses jalons configurables. Les versions se chevauchent façon "train" : la version suivante démarre avant la fin de la précédente.

Paramètres généraux

Cadence des sprints et zoom du board — versions, phases et jalons se configurent dans les cartes ci-dessous.
Enregistré ✓

Versions

Ajoutez, renommez ou retirez des versions — leurs dates pilotent directement les lignes du board.

Phases

Barres affichées sur chaque ligne du board. Début/fin exprimés en semaine + jour depuis le début de la version.

Jalons

Cochez pour afficher un jalon sur le board. Semaine + jour de la semaine, depuis le début de version — cliquez ensuite un jeton sur le board pour le déplacer sur une version précise (l'icône ↺ sous un jeton déplacé annule le déplacement).
Aucune version à afficher — ajoutez-en une dans la carte « Versions » ci-dessus.
