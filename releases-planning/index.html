Plan de livraisons de stabilisation

Une ligne par version, avec ses phases et ses jalons. Les versions se chevauchent façon "train" : la version suivante démarre avant la fin de la précédente. Éditez le nom, les phases et les dates d'une version directement sur sa ligne du board (icônes ✎ / 🗑).

Paramètres généraux

Cadence des sprints, zoom du board, et gabarit (durée par défaut de chaque phase) utilisé pour créer une nouvelle version. Les jalons se configurent dans la carte ci-dessous ; les phases et dates d'une version existante se modifient directement sur le board.
Enregistré ✓

Versions

Nouvelle version = nom suggéré + gabarit de phases ci-dessus. Pour renommer, changer les dates ou retirer une version existante, utilisez les icônes ✎ / 🗑 sur sa ligne du board plus bas.

Jalons

Cochez pour afficher un jalon sur le board. Semaine + jour de la semaine, depuis le début de version — cliquez ensuite un jeton sur le board pour le déplacer sur une version précise (l'icône ↺ sous un jeton déplacé annule le déplacement).
Aucune version à afficher — ajoutez-en une dans la carte « Versions » ci-dessus.
Ajustez les dates ci-dessous, ou faites glisser les poignées sur les barres de la ligne (bord bleu) — la date de début/fin de la version est la somme des 3 phases.
Maquette de préparation — phases, jalons et cadence de chevauchement restent à confirmer avec les squad leads avant diffusion. Barre rouge = date du jour.
